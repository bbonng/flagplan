# flagplan

플래그풋볼 수행평가 「작전 실행 계획서」

- `index.html` 학생용: 조별로 작전 3개를 손으로 그리고(직선 자동 보정), 기호·옵션·작전 설명을 적는다.
- `review.html` 선생님용 평가판: 학생이 제출한 계획서를 반·조별로 보기, 연습 기록, 계획서(조 점수)·실행(개인 점수) 채점. 반 목록 맨 아래 「예시 (연구회 시연)」은 예시 데이터.

제출은 조 비밀번호로 선생님 구글 시트에 저장된다. 저장소 코드는 공간작전판과 같이 쓰며 bbonng/flagboard의 `apps-script/Code.gs`에 있다.
점수·연습 기록은 아직 평가판을 연 기기에만 저장된다.
작전 그림은 야드 좌표(가로 25 × 세로 -9~21, 스크리미지 라인 0)로 저장되어 공간작전판(flagboard)과 같은 좌표계를 쓴다.
