# flagplan

플래그풋볼 수행평가 「작전 실행 계획서」

- `index.html` 학생용 (2026-10-22부터 [저장] 버튼 있는 판): 조별로 작전 3개를 손으로 그리고(직선 자동 보정), 기호·옵션·작전 설명을 적는다.
- `v1.html` 저장 버튼 넣기 전 학생용 (되돌릴 때 쓰는 보관본)
- `v2.html` index와 같음: 저장하면 선생님 시트의 [초안] 탭(조마다 한 줄)에 덮어쓰고, 다른 기기에서 조 로그인하면 그 초안(또는 더 최근 제출본)을 불러온다. 평가는 제출본으로만 한다. 저장소 코드(Code.gs)를 새 버전으로 올려야 저장이 켜진다.
- `v3.html` 시험판: index에 [경기에 뛰는 인원 5명/6명]을 더한 판. 조가 한 번 고르면 작전 3개 모두에 적용된다. 6명이면 W 선수(X와 C 사이)가 들어가고, 수비도 6명(2-2→2-3, 3-1→3-2), 옵션은 C·X·W·Y·Z에게 1~5를 모두 정한다. 5명 조는 지금과 똑같다. 써 보고 괜찮으면 index로 바꾼다.
- `review.html` 선생님용 평가판: 학생이 제출한 계획서를 반·조별로 보기, 연습 기록, 계획서(조 점수)·실행(개인 점수) 채점. 반 목록 맨 아래 「예시 (연구회 시연)」은 예시 데이터. 6명 조 계획서(v3)도 6대6·옵션 n/5로 보여 준다.

제출은 조 비밀번호로 선생님 구글 시트에 저장된다. 저장소 코드는 공간작전판과 같이 쓰며 bbonng/flagboard의 `apps-script/Code.gs`에 있다.
평가판의 계획서 점수·실행 점수·메모·「계획서만 참여」·연습 기록은 같은 시트의 [평가] 탭에 저장된다(2026-10-26부터, 저장소 코드를 새 버전으로 올려야 켜짐). 인터넷이 끊기면 패드에 보관했다가 연결되면 다시 보낸다. 처음 연결할 때 그 패드에만 있던 점수를 한 번 올린다. 시트 메뉴 [작전판 > 점수표 정리]로 [점수표] 탭(반·조·이름·계획서·실행·합계)을 만든다.
작전 그림은 야드 좌표(가로 25 × 세로 -9~21, 스크리미지 라인 0)로 저장되어 공간작전판(flagboard)과 같은 좌표계를 쓴다.
