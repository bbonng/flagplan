# flagplan

플래그풋볼 수행평가 「작전 실행 계획서」

- `index.html` 학생용 (2026-11-06부터 = v3): 조별로 작전 3개를 손으로 그리고(직선 자동 보정), 기호·옵션·작전 설명을 적는다. [경기에 뛰는 인원 5명/6명]을 조가 한 번 고르면 작전 3개 모두에 적용된다. 6명이면 W 선수(X와 C 사이, 초록)가 들어가고, 수비도 6명(2-2→2-3, 3-1→3-2), 옵션은 C·X·W·Y·Z에게 1~5를 모두 정한다.
- `v1.html` 저장 버튼 넣기 전 학생용 (되돌릴 때 쓰는 보관본)
- `v2.html` 5명/6명 선택을 넣기 전 학생용 (되돌릴 때 쓰는 보관본). 저장하면 선생님 시트의 [초안] 탭(조마다 한 줄)에 덮어쓰고, 다른 기기에서 조 로그인하면 그 초안(또는 더 최근 제출본)을 불러온다.
- `v3.html` index와 같음 (6명 조 시험판이었다가 2026-11-06에 index로 바꿈).
- `review.html` 선생님용 평가판: 학생이 제출한 계획서를 반·조별로 보기, 연습 기록, 계획서(조 점수)·실행(개인 점수) 채점.
  - 조를 열면 [계획서 채점] 화면: 작전 1·2·3 그림과 설명이 나란히, 아래에 계획서 점수(50·40·30·20). 태블릿 가로·노트북에서 스크롤 없이 한 화면에 들어온다. 그림을 누르면 [작전별 보기]로 크게, [이전 조]·[다음 조]로 넘긴다.
  - [제출]하지 않고 [저장]만 한 조도 「제출 안 함 · 저장본 있음」으로 그림을 보여 주고, 제출한 뒤 다시 고쳐 저장한 조는 따로 알려 준다(저장소 코드 새 버전 필요). 반 목록 맨 아래 「예시 (연구회 시연)」은 예시 데이터. 6명 조 계획서(v3)도 6대6·옵션 n/5로 보여 준다.

제출은 조 비밀번호로 선생님 구글 시트에 저장된다. 저장소 코드는 공간작전판과 같이 쓰며 bbonng/flagboard의 `apps-script/Code.gs`에 있다.
평가판의 계획서 점수·실행 점수·메모·「계획서만 참여」·연습 기록은 같은 시트의 [평가] 탭에 저장된다(2026-10-26부터, 저장소 코드를 새 버전으로 올려야 켜짐). 인터넷이 끊기면 패드에 보관했다가 연결되면 다시 보낸다. 처음 연결할 때 그 패드에만 있던 점수를 한 번 올린다. 시트 메뉴 [작전판 > 점수표 정리]로 [점수표] 탭(반·조·이름·계획서·실행·합계)을 만든다.
작전 그림은 야드 좌표(가로 25 × 세로 -9~21, 스크리미지 라인 0)로 저장되어 공간작전판(flagboard)과 같은 좌표계를 쓴다.
